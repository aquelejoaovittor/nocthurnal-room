# Como contribuir

Obrigado pelo interesse em Nocthurnal Room.

## Licenca das contribuicoes

Ao enviar codigo, voce concorda em licencia-lo sob AGPL-3.0-or-later,
preservando a marca "Nocthurnal Room" e a assinatura "Orbyte Studio"
(veja TRADEMARK.md).

## Fluxo

1. Abra uma issue descrevendo o problema ou proposta.
2. Faca fork, crie um branch (feat/..., fix/...).
3. Rode cargo test --workspace antes do PR.
4. Mensagens de commit no imperativo (add, fix, refactor).
5. PR precisa passar em cargo fmt --check e cargo clippy -D warnings.
